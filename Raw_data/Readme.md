# Raw Data

This project uses the Brazilian E-Commerce Public Dataset by Olist.

The original dataset contains multiple relational tables covering:

- Customers
- Orders
- Order Items
- Payments
- Reviews
- Products
- Sellers
- Geolocation
- Product Category Translation

The original raw files are not included directly in this repository to keep the repository lightweight.

The dataset can be obtained from the original public Kaggle source.
