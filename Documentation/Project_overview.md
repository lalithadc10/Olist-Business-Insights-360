#  What These Videos Demonstrate

Through these demonstrations, I aim to showcase my ability to:

- Translate a raw public dataset into **business-context questions**

- Build a structured **Power BI data model**
- Develop analytical measures using **DAX**
- Design interactive and business-focused dashboards
- Analyze sales, finance, customers, and supply chain operations
- Convert data into **actionable business insights**
- Communicate findings clearly to business stakeholders

> **The goal was not simply to create charts, but to use data to answer real business questions and support better decision-making.**
